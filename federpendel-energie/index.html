5. Physikalisches Modell

Auslenkung: x(t) = A · cos(ωt)

Kreisfrequenz: ω = √(D/m)

Geschwindigkeit: v(t) = −A · ω · sin(ωt)

Spannenergie: Espann = ½ · D · x²

Bewegungsenergie: Ekin = ½ · m · v²

Gesamtenergie: Eges = ½ · D · A² = konstant

Periodendauer: T = 2π · √(m/D)
